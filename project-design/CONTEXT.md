# AI 代码笔记与知识管理

围绕代码中的学习记录形成可追溯、可维护的主题知识，支持独立的个人知识空间与明确授权的多人编辑。

## Language

**知识空间（Knowledge Space）**：
属于一名拥有者的知识与资料集合，是个人内容管理的边界。空间中的部分成果可以授权他人访问。
_Avoid_: 企业租户、团队组织

**知识项目（Knowledge Project）**：
围绕一个学习方向或研究目标组织的资料与主题集合，可以关联多个来源目录。
_Avoid_: 单个代码仓库、单篇文章

**来源文件（Source File）**：
被用户纳入项目的原始代码文件，包含代码及其中的学习注释。
_Avoid_: 生成文档、整理结果

**来源快照（Source Snapshot）**：
某个来源文件在特定时刻的内容版本，是一次整理所依据的原始材料。
_Avoid_: 当前文件、最新文件

**来源片段（Source Fragment）**：
来源快照中一段有明确位置、可以一起理解的代码和注释。
_Avoid_: 无来源文本、整篇文档

**学习笔记（Learning Note）**：
用户记录在来源代码中的理解、疑问、例子和经验，是整理知识的原始输入。
_Avoid_: AI 补充结论

**主题（Topic）**：
一个有明确知识问题或学习目标的组织单位，可以关联多个来源文件及其片段。
_Avoid_: 文件名、文件夹

**主题大纲（Topic Outline）**：
某个主题下知识内容的章节组织，说明讲解顺序及各部分的关系。
_Avoid_: 文件列表

**知识文档（Knowledge Document）**：
围绕主题形成、供人阅读和编辑的知识成果，包含解释、代码引用、图解及参考依据。
_Avoid_: 来源文件、未经整合的候选稿

**文档修订（Document Revision）**：
一次成功保存的完整文档内容及其来源记录，可以用于比较和恢复历史内容。
_Avoid_: 覆盖备份、任务状态

**生成基线（Generation Baseline）**：
上一次已完成整合的 AI 生成内容，是判断后续人工修改与新生成内容关系的依据。
_Avoid_: 当前展示稿、任意历史版本

**候选稿（Candidate Draft）**：
AI 根据一组明确资料生成、尚未完成整合的内容。
_Avoid_: 最新正式文档

**人工修改（Human Edit）**：
拥有编辑权限的人对知识文档作出的内容变更，包括解释、代码展示和图解的调整。
_Avoid_: 原始代码变更

**更新冲突（Update Conflict）**：
多个修改影响同一内容，或在含义上互相矛盾，无法可靠自动合并的情况。
_Avoid_: 普通更新、生成失败

**证据（Evidence）**：
支持某个讲解或结论的来源内容，可以来自原始代码笔记或外部参考资料。
_Avoid_: 模型推测、无出处结论

**引用（Citation）**：
文档中的内容与其证据之间可追溯的关联。
_Avoid_: 仅列出的参考链接

**整理任务（Organization Job）**：
围绕确定的主题与资料，完成组织、补充、核查并产生候选稿的一次工作。
_Avoid_: 一次模型请求、整个项目

**来源同步（Source Sync）**：
把用户指定的本地来源变化反映到项目中的过程。
_Avoid_: 文档编辑、双向改写代码

**文档同步（Document Sync）**：
在客户端与服务端之间交换文档修订和待提交修改的过程。
_Avoid_: 来源同步、实时共同输入

**异步协作（Asynchronous Collaboration）**：
多人获得编辑权限，分别修改和保存同一文档，在保存时识别版本差异。
_Avoid_: 实时协同编辑、共同光标

**拥有者／编辑者／阅读者（Owner / Editor / Viewer）**：
分别表示负责内容及授权、可以修改获授权内容、可以阅读获授权内容的人。对某篇成果的权限不等于获得其整个知识空间。
_Avoid_: 所有登录用户、全局管理员
